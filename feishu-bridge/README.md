# @local/feishu-bridge

在飞书里直接和这个 Harness 对话。插件用飞书的 **WebSocket 长连接**接收事件，
不需要公网 IP、域名、TLS 证书或回调地址；服务器只要能主动访问
`open.feishu.cn`（Lark 租户则是 `open.larksuite.com`）即可。

- **一个飞书会话 = 一个持久 Harness Session**：私聊或群聊第一次发消息时自动建
  会话，之后的消息续在同一个 Session 里，重启 Harness 也不会丢上下文。
- **回复流式显示**：默认用飞书流式卡片边生成边显示；卡片失败时自动改发普通
  文本，再失败才报错。
- **支持文字和图片**：图片会下载后作为图片输入交给模型；语音、文件、视频目前
  只在提示里说明收到过，不读取内容。
- **群聊默认要求 @ 机器人**，并可按群、按私聊发送者做白名单。
- **设置页**可以填写 App ID / Secret、测试连接、查看长连接状态、重连和清除会话绑定。

## 在飞书开放平台准备应用

1. 打开 [飞书开放平台](https://open.feishu.cn/app)（Lark 用
   [open.larksuite.com](https://open.larksuite.com/app)），创建**企业自建应用**。
2. **添加应用能力 → 机器人**。
3. **权限管理**里至少开通：
   - 读取用户发给机器人的单聊消息；
   - 获取群组中 @ 机器人的消息（或“获取群组中所有消息”，按你的安全要求选择）；
   - 以应用身份发消息（`im:message:send_as_bot`）；
   - 获取与上传图片或文件资源（读取图片时需要）；
   - 获取群组信息（可选，仅用于把群名写进 Session 标题）。
4. **事件与回调 → 事件配置**：订阅方式选择**使用长连接接收事件**，添加
   `im.message.receive_v1`（接收消息）。不要填请求地址。
5. **版本管理与发布**：创建版本并发布。企业需要管理员审核通过后机器人才可用。
6. 把机器人加进群，或从飞书搜索机器人发起私聊。

> 长连接只影响“事件怎么进来”。应用仍然需要发布并获批，机器人才能收发消息。

## 在 Harness 里启用

1. 安装并启用本 bundle（Plugins → Add plugin，或 `dsh plugin add`）。
2. 打开 **Settings → 飞书长连接**。
3. 填入 App ID（`cli_…`）和 App Secret。
4. 点 **测试连接**：成功时会显示机器人名称；再点 **保存并连接**。
5. 私聊机器人发一句话，或在群里 @机器人 发一句话。

App Secret 会写进 profile 的 `cordis.patch.yml`。如果不想把密钥落盘，可以在
该字段填 `$FEISHU_APP_SECRET`，插件会从 Harness 进程环境读取。

## 可调选项

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 启用 | 开 | 关闭后保留配置，断开长连接 |
| 域名 | 飞书 | 飞书或 Lark |
| 工作目录 | profile 下 `feishu-bridge/home` | 新会话的工作目录 |
| 预设 | 默认预设 | 指定飞书会话使用的 agent preset |
| 私聊策略 | 所有人 | `open` / `allowlist`（填 open_id）/ `disabled` |
| 私聊白名单 | 空 | 允许私聊的发送者 open_id，每行一个 |
| 群白名单 | 空 | 允许的群 chat_id（`oc_…`），每行一个；空表示不限制 |
| 群聊必须 @ | 开 | 关闭后群里每条消息都会进入智能体，慎用 |
| 响应 @所有人 | 关 | 是否响应 @所有人 的消息 |
| 流式卡片 | 开 | 关闭后等整段回复完再一次性发送 |
| Markdown | 开 | 用飞书富文本发送；失败自动退回纯文本 |
| 话题回复 | 关 | 在话题群里回复到话题内 |

## 行为与限制

- 群里一条消息只在该消息 @ 了机器人时进入智能体（默认）；私聊没有这个限制。
- 同一个会话里的连续消息会按顺序排队；每轮结束把最终回复发回飞书。
- 一次回复很长时由飞书 SDK 自动分段；流式卡片超出元素上限时 SDK 会自动换卡。
- 目前一个飞书群对应一个 Session，不按话题或发言人拆分。
- 不支持在飞书里审批 Harness 的工具权限：需要审批的工具会按当前会话的权限
  策略执行或拒绝。
- 飞书长连接断线由 SDK 自动重连；设置页可查看最近错误并手动重连。
- 清除绑定只会让下一条消息新建 Session，不会删除已有会话记录。

## 排错

| 现象 | 检查 |
| --- | --- |
| 测试连接报 `app id not found` / `invalid app secret` | 复制的是应用凭证页的 App ID / App Secret，不是 Verification Token |
| 连上了但收不到消息 | 事件订阅方式是否为“长连接”，是否订阅 `im.message.receive_v1`，应用版本是否已发布 |
| 私聊有回复、群聊没有 | 群里是否 @ 了机器人；群白名单是否漏了这个群；`requireMention` 是否开启 |
| 能收到但不能回复 | 是否开通“以应用身份发消息”；机器人是否被移出会话 |
| 图片没有进入模型 | 图片权限、大小（>8 MiB 会跳过）和格式（png/jpeg/webp/gif） |
| 卡片只显示“正在处理…”后失败 | 租户未开放卡片流式能力时会自动改发文本；仍失败请查看 Host 日志 |

Host 日志里以 `feishu-bridge:` 开头的行包含连接、消息处理和发送错误。
